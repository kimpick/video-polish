# 배경음(CC0) 출처와 이력

기준: **CC0 표기**이고 상업 이용 가능한 곡만. 곡 페이지에서 라이선스를 곡마다 확인한다(모음 페이지의 표기만 믿지 않는다). 곡명·제작자·출처 링크는 전달 보고에 남긴다.

## 출처 상태 (2026-10-13 기준)
- **OpenGameArt** (opengameart.org): CC0 필터 가능. 직접 다운로드 링크가 공개돼 있다. 루프 곡이 많아 길이가 짧다.
- **itch.io 팩**: 곡 수는 많지만 클릭 흐름이 필요하다. "anamnesis" 팩(efilheim, CC0, wav)은 앰비언트·SF 톤이라 **사용자가 "공허하다"고 평가**했다. 밝은 분위기가 필요하면 쓰지 않는다.
- **FreePD**: 사이트 폐쇄(2026-10-13 확인). 쓰지 않는다.
- 피할 것: Pixabay Content License·BudgetPixel·ende.app(CC BY, 크레딧 필요)·Payhip 유료 음원은 CC0가 아니다.

## 검색 요령
- 분위기를 먼저 정한다: 밝은 / 잔잔한 / 진중한 / 경쾌한 어쿠스틱.
- OpenGameArt 검색어 예: `CC0 upbeat cheerful piano loop`, `happy acoustic loop`, `ukulele`. 태그 `loop`, `happy`, `upbeat`.
- 영상 길이(예: 4분 41초)보다 짧은 루프는 반복된다. 반복이 거슬릴 수 있어 길이를 후보 표에 적는다.

## 사용 이력
| 곡 | 제작자 | 형식·길이 | 분위기 | 결과 |
|---|---|---|---|---|
| [Happy Clappy Loop](https://opengameart.org/content/happy-clappy-loop) | OwlishMedia | wav, 17.4초 | 밝은 피아노 | 추천으로 채택. 이음매 매끄러움. 평균 -22.8dB → 볼륨 0.45~0.49 |
| [Happy Vibes](https://opengameart.org/node/160228) | Ruskerdax | mp3, 45.5초 | 레트로 신스, 섬 느낌 | 비교용. mp3 이음매에 무음 틈. 평균 -11.7dB → 볼륨 0.14 |
| anamnesis 팩 01~07 | efilheim | wav, 199~315초 | 앰비언트 | 사용자가 "공허하다"며 기각 |

## 다운로드 규칙
- 파일명·출처·용량을 사용자에게 말하고 **승인 후** 받는다. 받은 파일은 작업 폴더의 `bgm\`에 둔다.
- 자동 분류기가 다운로드 명령을 막으면 우회하지 말고, 링크를 주고 사용자가 직접 넣게 한다(설치 exe는 막혔고 음원은 통과한 전례가 있다).
- mp3는 wav로 바꿔도 이음매 틈은 남는다. 반복이 필요하면 wav 원본을 우선한다.
